AI 面试

这里面向 AI 应用工程师和希望转向 AI 方向的开发者，不做只有答案、没有上下文的题库。重点是能解释原理、讲清项目取舍，并根据证据回答系统设计问题。

AI 面试：5 篇核心文章

  1. AI 项目面试怎么讲：用问题、取舍和证据替代框架清单
  2. RAG 面试高频问题：切分、检索、重排和评测怎么回答
  3. Agent 面试高频问题：Tool Calling、工作流和安全边界
  4. 大模型推理面试：首 Token 延迟、吞吐量和 KV Cache
  5. AI 系统设计面试：如何设计一个可上线的知识库问答服务

01 · 大模型基础

后续将围绕 Python、网络、数据库、并发和常见工程问题整理可验证的知识点。每个问题都尽量说明适用条件、常见误区和实际案例。

02 · AI 工程问题

重点包括：

  • 如何解释一次模型调用的完整链路；
  • RAG 的切分、检索、重排序和评测；
  • Agent 工具调用的权限与失败处理；
  • 推理服务的延迟、吞吐量、并发和显存；
  • 如何区分 Demo、原型和可上线系统。

03 · 项目表达

推荐使用以下顺序介绍项目：

问题与约束
  -> 你的职责
  -> 技术选择
  -> 最难的问题
  -> 验证结果
  -> 失败与改进

不要只罗列框架名称。面试官更关心为什么选择、如何验证，以及出现故障时你做了什么。

04 · AI 系统设计

系统设计内容将从小型 AI API 开始，逐步讨论缓存、队列、限流、可观测性、数据一致性和推理资源调度。

推荐阅读顺序

先学习项目表达，再依次阅读 RAG、Agent 和推理性能，最后用系统设计文章把检索、模型服务、权限、评测与可观测性串起来。阅读时为自己的项目准备真实指标和失败案例，不要只背结论。
