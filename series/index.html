AI 专题路线

专题页用于把零散文章组织成可以持续推进的工程路线。标记为“建设中”的内容只代表后续计划，不代表已经完成。

01 · AI 工程入门｜已有内容

目标：从调用模型开始，逐步做出有输入边界、错误处理和验收标准的 AI 应用。

  • 零基础学大模型：8 周开源项目路线

  • Python 新手学 AI：7 个两天内能做完的开源项目

  • 大模型学习资料推荐：从入门、RAG 到推理部署

  • AI 入门第一课：Token、Embedding 和文本生成

  • Transformer 入门：一次文本生成经历了什么

  • 开源大模型怎么选：参数、量化、上下文和硬件

  • Ollama + Python：稳定返回结构化 JSON

  • FastAPI 构建 AI 服务

02 · 可靠 RAG 系统｜已有入门文章

目标：构建一个能够引用来源、接受评测并说明失败原因的知识库系统。

  • 不用 LangChain，自己实现一个可评测的最小 RAG
  • RAG 面试：切分、检索、重排和评测

计划顺序：

最小检索实现
  -> 文档切分与 Embedding
  -> 混合检索与重排序
  -> 引用溯源
  -> 自动评测
  -> API、部署与压测

03 · 可控 Agent｜已有入门文章

目标：理解工具调用循环，并处理权限、超时、重试、状态恢复和可观测性。

重点不是“让 Agent 自己做一切”，而是明确它能做什么、什么时候停止，以及失败后如何恢复。

  • Tool Calling Agent：从工具调用到安全执行循环
  • Agent 面试：Tool Calling、工作流和安全边界

04 · 推理与部署｜已有基础文章

目标：使用可重复的测试比较本地与服务端推理方案。

后续将围绕首字延迟、吞吐量、并发、显存、量化和批处理组织实验，并公开测试环境与原始结果。

  • 开源大模型怎么选：参数、量化、上下文和硬件
  • 大模型推理面试：首 Token 延迟、吞吐量和 KV Cache
  • Mac 本地部署大模型：从 Ollama 安装到性能调优

05 · 多模态生成｜已有入门文章

目标：在 Mac 上理解图片与视频生成工作流，并用可复现参数完成一次从文字、图片到短视频的实验。

  • Mac AI 图片与视频生成：用 ComfyUI 跑通第一个完整工作流
