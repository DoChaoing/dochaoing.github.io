从 0 到 1 的大模型学习路线

这不是“AI 名词大全”。路线从能看懂模型、能完成小实验开始，逐步走向应用、Agent 与推理部署。每一步都有代码、数据、评测或压测作为产出。

从哪里开始

先读：从 0 到 1 学大模型：别从 Agent 开始，先完成这四个开源项目

资料筛选与难度说明见：大模型优质学习资料库。

如果你希望从 Python 实战开始，接着读：Python 新手可上手的 7 个开源 AI 项目。

文章提供了按难度分层的项目、开源仓库、八周节奏和每阶段的完成标准。开始前只需要选清楚自己的目标：做 AI 应用、理解模型训练，还是做推理与部署。

推荐顺序

tokenizer / attention 小实验
  -> 小 GPT 训练与评测记录
  -> 结构化输出的小应用
  -> RAG 与受限工具调用
  -> 推理服务与压测

资料原则

  • 优先官方课程、论文作者的代码仓库和活跃的开源项目；
  • 每次学习都留下可运行代码或实验记录；
  • 遇到“最新技术”先写出要验证的收益，再决定是否投入；
  • 不以模型参数量、框架数量或截图数量作为学习成果。
