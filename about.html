关于 Chao Blog

定位

Chao Blog 是一个面向开发者的 AI 工程实践博客，关注如何把模型能力变成可以运行、测试和部署的系统。

核心方向是：从开源项目出发，把大模型技术做成可以运行、评测和部署的工程系统。

这里不会把名词整理、框架安装或成功截图直接当成学习成果。文章会尽量交代环境、代码、验收方式、失败情况和已知限制。

当前主线是：

模型原理
  -> 小模型训练
  -> 结构化 AI 应用
  -> RAG / Agent
  -> 推理与部署

四条内容主线

方向 说明
AI 工程入门 从 Python 脚本到结构化、可测试的 AI 服务
可靠 RAG 检索、重排序、引用溯源、评测与部署
可控 Agent 工具调用、权限、超时、重试与可观测性
推理部署 KV cache、量化、吞吐、延迟与压测

目标

本站希望帮助读者完成三件事：

  1. 根据目标选择应用、模型或基础设施方向；
  2. 完成一个能运行、能解释、能验证的成果；
  3. 通过代码、数据和复盘逐步建立可靠的工程判断。

内容标准

一篇完整的实践文章应尽量包含：问题、运行效果、环境、最小实现、核心原理、测试结果、失败情况、改进方向和源码。

如果内容尚未完成验证，会明确标记为“规划中”或“建设中”，不把计划写成已经完成的成果。
